# Enat Elderly Care Service

A responsive website for an elderly care service, designed to present care services, introduce caregivers, and provide an easy way for visitors to get in touch.

## Features

* **Home Page:** Introduction to the elderly care service.
* **Caregivers Page:** Displays caregiver information.
* **Services Page:** Presents available care services.
* **Contact Page:** Includes a contact form for inquiries.
* **Responsive Design:** Adapts to different screen sizes.
* **Interactive Navigation:** Highlights the active page.
* **Form Validation:** Checks contact form inputs using JavaScript.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/firdauskedir/Enat-Elderly-Care-Website.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## Note

The contact form is a front-end demonstration. Submissions are not sent or stored because a backend service has not been connected.

## Purpose

This project was developed to practice front-end web development and create a user-friendly website for an elderly care service.
